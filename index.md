## Description

Minimal Course is a Jekyll template for course websites. It is designed to be **as minimal as possible**{:.important} yet easily maintainable for the instructor. The template is adapted from [minimal](https://github.com/orderedlist/minimal) by [orderedlist](https://github.com/orderedlist). Please follow the [instructions](https://github.com/salu133445/minimal-course) to create a course website using the Minimal Course theme.

Example course websites built with Minimal Course include:

- [Music and AI](https://hermandong.com/teaching/pat463_563_fall2026/) (PAT 463/563, University of Michigan)
- [Generative AI for Music and Audio Creation](https://hermandong.com/teaching/pat464_564_winter2026) (PAT 464/564, University of Michigan)
- [Creative Coding](https://hermandong.com/teaching/pat204_504_fall2026) (PAT 204/504, University of Michigan)
